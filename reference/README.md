# reference/ — material local, fora do Git

Esta pasta guarda o material de referência **pago** (livro de regras, fichas oficiais) usado para consultar as regras durante o desenvolvimento.

- Tudo aqui dentro é ignorado pelo Git, exceto este README.
- **Nunca** faça commit de PDFs, páginas escaneadas, prints ou texto extraído do livro.
- Cada colaborador coloca aqui a **própria cópia** comprada do livro.

Arquivos esperados (cada um na sua máquina):

| Arquivo | Uso |
|---|---|
| `Ordem Paranormal RPG.pdf` | Livro básico (2022, v1.3), base do ruleset `op2022` |
| `Ordem Paranormal - Ficha de Personagem (1).pdf` | Ficha oficial, referência para a UI da ficha |

Ao transcrever regras para `game/data/rulesets/`, registre **números e estruturas** (tabelas, DTs, custos) e escreva descrições **com palavras próprias**. Indique a página do livro no campo `ref`, por exemplo `"ref": "p.33"`. Veja [docs/03-legal-e-conteudo.md](../docs/03-legal-e-conteudo.md).
